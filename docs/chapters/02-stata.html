Stata-Kernel-Jupyter 扩展 · 豆包工作连接器 · 科研平台

Stata-Kernel-Jupyter 扩展简介、在豆包工作中的使用入门指南与计量经济网科研平台综合应用

计量经济网 · 数量经济学

关键词

Stata-Kernel-Jupyter, VS Code 扩展, MCP 连接器, 豆包工作

Stata-Kernel-Jupyter

Run Stata in VS Code / Jupyter notebooks / Quarto — with a persistent session, rich outputs, and built-in AI Agent (MCP) support.

在 VS Code / Jupyter / Quarto 中直接运行 Stata —— 常驻会话、富结果输出、内置 AI Agent（MCP）支持。

作者 / Author：Econometric 计量经济网 · www.aistata.cn

English

Open any .ipynb, switch the kernel to Stata (Stata-Kernel-Jupyter), and write Stata code. Results — logs, graphs, and auto-rendered coefficient tables — appear inline, in a persistent Stata session (no cold start per cell).

Highlights

🧭 Activity-bar sidebar Four views: Overview / Environment & Kernel / Current Session / Documents & Formats. Environment status, variables and e(b) at a glance.
🚀 Persistent session Stata launches once. Every cell runs in ~0.1–1s with full data/macro state retained across cells.
📊 Rich outputs Full log stream, inline PNG/SVG graphs, and e(b)/e(V) coefficient tables auto-rendered as HTML with significance stars.
📓 Jupyter-native Real ipykernel: code-completeness detection (foreach/program/#delimit), Tab completion, Shift+Tab help, interrupt support.
🪄 Magics %head %tail %browse %describe %sum %tab %locals %help %set %png %svg %restart (also *% prefix — survives .do export) and %%stata -g / -q cell magic.
📄 Quarto & Markdown One-click .do → .ipynb and .ipynb → .qmd conversion; run ``{stata} chunks in.qmd/.mdvia CodeLens; export HTML (Quarto CLI preferred). | | 🤖 **AI Agent ready** | Built-in MCP server (stata_run/stata_help/stata_dataset) with structuredRunResult v1JSON + image outputs. One command registers it to **VS Code Chat/agent tools**, Claude, Cursor, Windsurf, Cline, Roo Code, WorkBuddy and more. | | 🔌 **Driver fallback** | PyStata (Stata 17+, in-process) → resident worker (persistent process) → CLI batch. Auto-detected. | | 🇨🇳 **中文友好** | Chinese docs/UI, UTF-8 full pipeline, CN mirror install, common community commands (reghdfe,esttab,winsor2`…) built into completion.

Quick start

  1. Install this extension from the VS Code Marketplace.
  2. Click the Stata icon in the Activity Bar → Overview → 一键注册内核 (or the Stata 内核 status-bar item). The wizard auto-detects Python, Stata, installs the kernel package and registers the Jupyter kernelspec.
  3. Open a .ipynb → kernel picker → search Stata → run:
sysuse auto, clear
regress price mpg weight

Commands

Command Description
一键注册 Jupyter Stata 内核 One-stop wizard: environment check → package install → kernelspec registration → verify
环境体检 (doctor) Diagnose Stata / Python / ipykernel / Quarto availability
把 .do 文件转换为 Notebook Split a .do file into notebook cells (auto-binds the Stata kernel)
把 .ipynb 转换为 Quarto Convert notebook to a Quarto .qmd
执行当前 .qmd/.md 中的全部 Stata 代码块 Run all {stata} chunks in one session, write results back
导出为 HTML Render .qmd/.md/.ipynb to HTML
把 Stata MCP 注册到 AI 客户端 Write the MCP server config to supported AI clients

Settings

Setting Description Default
skj.pythonPath Python interpreter used to run the kernel auto-detect
skj.stataExe Stata executable path (or env STATA_EXE) auto-detect
skj.driver auto / pystata / cli auto

CLI (included with the Python package)

pip install stata-kernel-jupyter[jupyter]
skj kernel install          # register the Jupyter kernel
skj doctor                  # environment check
skj run "reg y x" --json    # structured RunResult v1
skj install-agent           # register MCP to AI clients
skj quarto run paper.qmd    # execute all {stata} chunks
skj html paper.qmd          # render HTML

Requirements

  • Stata 16–19 (MP/SE/BE) installed locally
  • Python ≥ 3.9 with ipykernel (the wizard installs what is missing)
  • Optional: Quarto CLI for best HTML/PDF rendering

Stata-Kernel-Jupyter 在豆包工作中的使用入门指南

Stata-Kernel-Jupyter 在豆包工作中的使用入门指南

本文档基于 豆包工作 中实测调用 Stata-Kernel-Jupyter 连接器（MCP）的全过程整理

适用环境：Windows 桌面版豆包工作 + Stata 18+ Anaconda Python。

1. 简介

Stata-Kernel-Jupyter 是一个 MCP（Model Context Protocol）服务器，作用是让 AI Agent（豆包工作）能够直接驱动本机安装的 Stata 执行代码，并返回结构化结果（日志、统计表、系数表、图形）。

  • 技术形态：stdio 类型 MCP 服务器，通过 JSON-RPC 与豆包工作通信
  • 服务器自报信息：Stata-Kernel-Jupyter
  • 注册名称：在豆包工作连接器中显示为 Stata-Kernel-Jupyter

一句话概括：在豆包工作里，让 AI 帮你跑 Stata、看结果、存文件。

2. 功能特性**

2.1 相关工具

由于数量经济学微信公众号还开发了其他AIStata MCP系列智能体，所以近期更新的Stata-Kernel-Jupyter MCP目前只提供如下3个工具，最基础的 Stata 运行代码相关功能包括在内（这是最核心的）

工具名（豆包工作中完整名） 短名 作用 参数
mcp__stata_kernel_jupyter__stata_run stata_run 执行 Stata 代码，返回结构化结果（日志 / e() 标量宏 / e(b) 系数表 / 图形） code（必填）、echo（默认 true）
mcp__stata_kernel_jupyter__stata_help stata_help 查询 Stata 命令帮助文档 topic（必填）
mcp__stata_kernel_jupyter__stata_dataset stata_dataset 查看当前内存数据集的变量列表（名称 / 标签 / 类型） 无

2.2 返回结果结构（RunResult）

  • log：Stata 完整输出日志
  • graphs：自动导出的图形文件路径（PNG），MCP 会以图片形式返回会话
  • structured：e() 标量 / e(b) 系数表（PyStata 驱动下才有）
  • error：错误信息（kind / message / rc），如 r(198)

3. 在豆包工作中添加连接器

  1. 打开豆包工作 → 连接器 / MCP 设置界面
  2. 添加 MCP 服务器，选择 Stata-Kernel-Jupyter
  3. 确认连接器状态为「已连接」
  4. 新开一个会话，验证工具是否注册成功

4. 在豆包工作中调用

4.1 推荐方式：自然语言直接说需求

无需指定工具名，直接描述任务即可，我会自动调用连接器：

场景 说法示例
跑分析 「用 Stata 跑一下 regress price weight mpg」
加载数据 「用 stata_run 加载 mydata.dta 并查看前几行」
查帮助 「帮我查一下 Stata 里 xtreg 的帮助」
看数据集 「看看当前 Stata 内存里有哪些变量」
多步任务 「用 auto 数据跑个回归，再解释下系数」

4.2 点名工具方式

明确指定工具名（适合精确控制）：

  • 「调用 stata_run 执行 sysuse auto, clear 和 summarize」
  • 「用 stata_help 查 regress」
  • 「调用 stata_dataset 看当前数据集」
